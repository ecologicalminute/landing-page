# Momento Ecológico — Site V2

Reconstrução completa do site com base na dissertação enviada e na imagem de referência visual.

## Páginas
- index.html — Início
- pesquisa.html — A pesquisa
- cerrado.html — O Cerrado
- podcast.html — Podcast
- guia.html — Guia didático
- sobre.html — Mestrando e UnB
- styles.css — identidade visual e responsividade

## Observações
- O conteúdo textual foi estruturado a partir da dissertação de qualificação enviada pelo autor.
- A dissertação informa que os links dos episódios estavam “em construção”; por isso os links definitivos não foram inventados.
- A dissertação também informa que não houve intervenção pedagógica/aplicação direta com estudantes; o site não apresenta eficácia pedagógica como resultado comprovado.
- A área do retrato do mestrando está preparada para receber uma fotografia real posteriormente.
- A composição visual do hero foi criada em CSS para reproduzir a linguagem da referência (verde, dourado, creme, paisagem, microfone e guia didático) sem depender de imagens externas.
